# Solitary Chess

Solitario de ajedrez educativo: cada movimiento debe capturar una pieza, y ganas cuando queda una sola sobre el tablero.

## Características

- Niveles progresivos (3×3, 4×4, 5×5) con desbloqueo secuencial y puntuación.
- Modo libre con tipos de pieza y número de piezas configurables.
- Temas visuales: Clásico, Mármol y Neón, con modo claro/oscuro.
- Progreso guardado en el navegador (localStorage).
